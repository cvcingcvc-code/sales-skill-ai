## 3. 问题陈述

### 真实痛点：线下销售团队的"话术黑洞"

中国有数千万线下销售从业者——保险代理人、银行理财顾问、教育顾问、地产销售——他们的核心竞争力是**当面说服客户的能力**，但这种能力的培养方式至今停留在：

- **老人带新人**：效率极低，老人时间成本高，新人被动等机会
- **背话术手册**：静态文字，无法模拟真实客户的反应和压力
- **开会复盘**：事后诸葛，错误已经发生，客户已经流失
- **培训效果无量化**：管理者不知道哪个环节最弱，无法针对性训练

**核心矛盾**：销售能力需要通过"真实对抗"来提升，但真实客户不能拿来练习。

### 数据参考

- 保险行业新人平均 3 个月内流失率超 60%，核心原因之一是遭遇拒绝后没有复盘支持
- 一个销售主管平均带 8-15 名新人，每天能给每人的辅导时间不超过 20 分钟

## 4. 解决方案

### 核心思路：把 AI 变成"永不疲倦的陪练客户"

**销售神队友**提供三个递进能力：

#### 🎓 能力一：话术知识库（Learn）
结构化存储企业标准话术，覆盖：
- 产品价值介绍（FABE 框架）
- 高频异议处理（价格/竞品/时机/决策人）
- 成交推进话术

企业可上传自己的话术库，系统自动结构化入库。

#### 🎭 能力二：AI 客户模拟（Practice）
Gemini 扮演真实客户，具备：
- **具体人设**：职业、性格、顾虑点、预算范围（隐藏）
- **动态配合度**：好话术让 AI 客户松动，差话术让 AI 客户更抵触——不是固定脚本
- **真实结局**：每次对话有明确结果（成交 / 拒绝 / 跟进），不会无限循环
- **多种场景**：陌拜、回访、价格谈判、异议处理

#### 📊 能力三：逐维评分 + 改进建议（Improve）
对话结束后，AI 以"资深销售主管"视角给出：
- 5 个维度打分（0-100）：开场、需求挖掘、价值传递、异议处理、促成成交
- **引用具体对话片段**，不泛泛而谈
- 给出"改进后示范话术"，可以直接学
- 推荐下一步练习场景

#### 🤖 能力四：Agent Skill 接口（Scale）
以上三个能力封装为标准化 HTTP 接口，供外部 Agent 调用：
- 企业自动化培训 Agent 可在入职流程中自动触发训练
- 支持批量生成训练报告

### 产品流程图

```
[新员工] → 选择场景 → AI扮客户开场 → 多轮对话练习
                                              ↓
                               [对话结束：成交/拒绝/跟进]
                                              ↓
                               AI评分（5维度）+ 片段分析
                                              ↓
                               推荐下次练习场景 → 循环提升
                                              ↓
                          [学员进度存入 SQLite] → 管理者查看团队报告

[外部Agent] → POST /skill/invoke → 同上流程 → 返回结构化结果
```

### 核心 Prompt 展示

**Prompt 1 — 客户角色扮演**（这是整个产品的灵魂）

```
你是一位{customer_name}，{occupation}。
性格：{personality}
当前顾虑：{pain_points}
对推销员的初始态度：冷漠/警惕

规则：
- 你是真实客户，不知道对方在练习销售
- 根据对方话术质量动态调整态度：
  好话术 → 逐渐松动，开始认真听
  差话术 → 更加抵触，找借口结束对话
- 语言自然，像真人说话，不用教材体
- 对话结束时在最后一行输出：
  [RESULT: success|reject|followup]
```

**Prompt 2 — 话术评分**

```
你是有15年经验的销售培训师，请评估以下对话。

场景：{scenario_name}，销售目标：{objective}
对话记录：{transcript}

严格按以下JSON输出，不要有其他文字：
{
  "total_score": 0-100,
  "dimensions": {开场, 需求挖掘, 价值传递, 异议处理, 促成},
  "strengths": ["具体优点，引用原文"],
  "weaknesses": ["具体问题，引用原文"],
  "suggestions": [{"issue": "...", "better": "...", "example": "..."}]
}

要求：每条评语必须引用对话中的具体句子，不接受"话术较弱"这种泛泛描述。
```

**Prompt 3 — 个性化推荐**

```
学员最近5次训练数据：{scores}
持续弱项：{weak_dimensions}

请输出JSON：
{
  "one_line_feedback": "鼓励为主，点出最关键问题",
  "focus_this_week": ["最多2个方向"],
  "recommended_scenarios": ["场景ID×3"],
  "golden_phrase": "一句本周可以直接用的话术金句"
}
```

### 开发工作流（"Coding 既是手段也是产物"）

本项目完整使用 **Claude Code**（Anthropic 命令行 AI 编程工具）开发：

1. 将架构设计写成 `CLAUDE.md`（即给 AI 的指令文档）
2. 在终端运行 `claude`，加载 `CLAUDE.md`，逐模块生成代码
3. Claude Code 生成代码 → 人工测试 Prompt 效果 → 反馈调整 → 再生成
4. 核心 Prompt 由人工迭代，代码框架由 AI 生成

**整个项目约 80% 的代码由 AI 生成，20% 为人工 Prompt 调优与场景设计。**

## 7. 影响力与可持续性

### 直接影响

- **目标用户**：国内数千万线下销售从业者（保险/银行/教育/地产）
- **核心价值**：将原本依赖"老人带新人"的隐性经验，转化为可量化、可复用的数字资产
- **量化收益预估**：新员工上手时间缩短 30-50%，话术异议处理成功率提升（待实测）

### 可持续性

**商业化路径**：
1. **SaaS 订阅**：企业按席位付费，包含话术库托管 + 训练报告
2. **话术库市场**：垂直行业（保险/银行/教育）的标准话术包可作为付费内容出售
3. **Agent 接口**：API 调用计费，供企业内部自动化培训流程集成

**技术可持续性**：
- 话术库为 JSON 格式，企业可自行维护和扩充
- Skill 接口标准化，模型层可随时切换（Gemini/Claude/本地模型）
- 数据留存在企业本地（SQLite），无数据泄露风险

**扩展方向**：
- 增加语音输入（模拟真实打电话场景）
- 多语言话术库（支持出海销售团队）
- 与 CRM 系统打通，基于真实客户数据生成训练场景
