## 一、问题陈述

**1. 你解决的是谁的什么问题？**

中国数千万线下销售从业者（保险代理人、银行理财顾问、教育顾问、地产销售）的核心竞争力是当面说服客户的能力，但新员工没有任何安全的环境来练习这种能力——真实客户不能拿来练手，练习的代价是直接流失潜在客户。

**2. 这个问题以前是怎么被解决的？**

- **老人带新人**：效率极低，老员工时间成本高，新人被动等机会
- **背话术手册**：静态文字，无法模拟真实客户的反应和压力
- **开会复盘**：事后诸葛，客户已经流失才知道哪里说错了
- **培训效果无量化**：管理者不知道每个人的弱点在哪，无法针对性辅导

**3. 为什么用 AI 能比之前更好地解决？**

AI 可以 7×24 小时扮演有具体人设的客户，根据业务员的话术质量动态调整反应——说得好客户会松动，说得差客户直接拒绝。每次对话结束后，AI 还能以"资深销售主管"视角逐句评分，给出可执行的改进建议。这是任何人工培训都无法规模化复制的能力。

## 二、解决方案

**1. 你的产品或作品是什么？**

销售神队友是一个可嵌入企业内训流程的 AI 话术训练 Skill。它包含三个核心能力模块：话术知识库（Learn）、AI 客户模拟对话（Practice）、逐维度评分与改进建议（Improve）。整个系统最终封装为标准化 Agent Skill 接口，可被企业自动化培训流程直接调用。

**2. 用户怎么用它？描述一个典型使用场景。**

新入职的保险业务员小李，入职第一天打开系统，选择"陌拜·企业主"场景。AI 扮演一位警惕推销的中小企业主，用冷漠的语气开场："你好，我很忙，有什么事快说。"小李输入开场白，AI 根据话术质量动态回应。10 轮对话结束后，AI 给出评分报告：开场得分 65，需求挖掘 40（最弱项），并引用对话原文指出"你在第 3 轮直接介绍产品，没有先问客户现在的保障情况"，同时给出改进后的示范话术。小李当天可以反复练习，直到能稳定拿到 75 分以上再去见真实客户。

**3. 它最核心的功能或亮点是什么？**

**动态客户反应**：AI 客户不是固定脚本，好话术让客户逐渐松动，差话术让客户更抵触，最终给出明确结果（成交/拒绝/待跟进）。这是整个产品最核心的设计，也是与普通话术背诵工具的本质区别。

## 三、技术或创意实现

**用了哪些 AI 模型、API 或工具？**

| 工具 | 用途 |
| --- | --- |
| Google Gemini 1.5 Pro（Gemini Enterprise Agent Platform） | 核心模型：客户扮演 + 话术评分 + 个性化推荐 |
| Anthropic Claude Code | 开发工具：生成本项目约 80% 的代码框架 |
| Anthropic Claude API | 备用模型层，支持模型切换与能力对比 |

**整体技术架构或创作流程是怎样的？**

```
[用户/Agent] → CLI 或 FastAPI 接口
                    ↓
            Skill 引擎（Python）
     ┌──────────┬──────────┬──────────┐
     │ 话术知识库│ 场景模拟  │ 评分系统  │
     │ JSON 库  │roleplay  │scorer.py │
     └──────────┴──────────┴──────────┘
            LLM Client（可切换）
        Gemini API / Anthropic API
                    ↓
         SQLite 学员进度数据库
```

开发工作流：将架构设计写成 CLAUDE.md 指令文档 → Claude Code 逐模块生成代码 → 人工迭代 Prompt 效果 → 反馈调整再生成。

**最关键的技术亮点或创意亮点是什么？**

核心是客户角色扮演的 Prompt 设计：

```
你是一位{customer_name}，{occupation}。
性格：{personality}
当前顾虑：{pain_points}
初始态度：冷漠/警惕

规则：
- 你是真实客户，不知道对方在练习销售
- 根据对方话术质量动态调整态度：
  好话术 → 逐渐松动，开始认真听
  差话术 → 更加抵触，找借口结束对话
- 语言自然，像真人说话，不用教材体
- 对话结束时在最后一行输出：
  [RESULT: success|reject|followup]
```

话术评分 Prompt（5 维度，引用原文，不接受泛泛描述）：

```
你是有15年经验的销售培训师，请评估以下对话。
场景：{scenario_name}，目标：{objective}
对话记录：{transcript}

严格按以下JSON输出：
{
  "total_score": 0-100,
  "dimensions": {开场, 需求挖掘, 价值传递, 异议处理, 促成},
  "strengths": ["具体优点，引用原文"],
  "weaknesses": ["具体问题，引用原文"],
  "suggestions": [{"issue": "...", "better": "...", "example": "..."}]
}
```
