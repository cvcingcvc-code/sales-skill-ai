# V1 交付状态与后续步骤

本轮代码范围已实现：配置化模型网关、训练修复、独立商品/知识/会话存储、受管理事实答复、显式同意线索、人工接管、Streamlit管理页及网站文字页。实现方式和限制见 [ARCHITECTURE.md](ARCHITECTURE.md)，真实通过项与阻断项以 [ACCEPTANCE_REPORT.md](ACCEPTANCE_REPORT.md) 为准。

## 完成本轮真实验收所需

| 下一步 | 由谁处理 | 完成依据 |
| --- | --- | --- |
| 撤销历史公开密钥，确认调用和账单记录，安全配置新 `DEEPSEEK_API_KEY` | 账户持有人 | 在服务商控制台核验；不要在报告或聊天中粘贴密钥。历史撤销/轮换目前未验证 |
| 确认当前模型名称、官方 `DEEPSEEK_BASE_URL` 和网络准入 | 部署/环境管理者 | 运行环境可访问配置目标；配置草稿保存或静态检查不能代替实际请求 |
| 确认配置已注入并重启服务 | 部署/环境管理者 | API 和 Streamlit 新进程读取更新；平台仅向新任务注入时在新任务重试，不能把旧进程状态当作新配置结果 |
| 运行真实请求和合成客服闭环验收 | 已配置环境中的操作者 | `scripts/verify_live.py` exit 0 且报告 `PASS`；缺凭据、鉴权或网络问题保留 `BLOCKED` |
| 录入并审核真实商家商品、价格、链接、FAQ和售后政策 | 商家管理员 | 工作台真实资料验证；演示和验收脚本只含合成数据，不是可售商品 |
| 验证真实商品咨询、同意线索、人工队列及网站访问 | 商家与部署方 | 使用已审核资料和已授权测试账号；核对答复引用、联系方式保存边界、人工暂停和回复 |
| 网站上线前配置访问与运维边界 | 部署方 | 按 [DEPLOYMENT.md](DEPLOYMENT.md) 配置TLS、限流、私有管理入口、备份和保留/删除流程；本轮没有进行真实公网部署 |

真实模型验证完成后，应将报告保存到仓库外并更新交付验收记录，不提交凭据、客户敏感数据或运行数据库。模型行为不符合选择器或评分合约时，应记录失败和具体可复现输入；不能改用 Mock 将其记为真实成功。
